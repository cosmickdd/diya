# 🎵 Audio Files Directory

Place your soothing Indian classical & festive MP3 audio files in this directory:

- `1.mp3` (or `.1.mp3`) — Track 1 (e.g., Divine Sitar & Bansuri Flute)
- `2.mp3` (or `.2.mp3`) — Track 2 (e.g., Temple Bells & Festive Santoor)
- `3.mp3` (or `.3.mp3`) — Track 3 (e.g., Meditative Tanpura & Sacred Raag)

### Built-in Fallback
If any track file is not yet added, the player seamlessly falls back to a soothing built-in Web Audio API meditative Tanpura drone (C# Sa-Pa resonance) so the experience never falls silent!
